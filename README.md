A lightweight, cross-platform web app designed for architecture students and professionals to conduct instant site analysis on both desktop PCs and mobile devices. The tool calculates global sun positions and annual paths, offering key date selections for solstices and equinoxes. It automatically generates presentation-ready 2D diagrams and features an interactive 3D map viewport. In active development, future iterations will allow users to dynamically add or modify building geometry with real-time shadow updates, alongside a 3D solar radiation heatmap engine to streamline early-stage environmental design.
